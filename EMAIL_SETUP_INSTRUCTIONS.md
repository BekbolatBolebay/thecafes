# 📧 Email Verification Setup - Step by Step\n\n## IMPORTANT: Your .env.local Setup\n\nYou MUST have these variables in your `.env.local` file:\n\n```\nEMAIL_USER=your.email@gmail.com\nEMAIL_PASS=xxxx xxxx xxxx xxxx\n\nNEXT_PUBLIC_SUPABASE_URL=https://your-project.supabase.co\nSUPABASE_SERVICE_ROLE_KEY=eyJhbGc...\n```\n\n---\n\n## 🔴 If You're Getting \"Email service not configured\" Error\n\nThis means:\n- ❌ EMAIL_USER is missing\n- ❌ EMAIL_PASS is missing\n- ❌ .env.local is not set up\n\n**Solution:** Follow the steps below\n\n---\n\n## ✅ Gmail Setup (REQUIRED)\n\n### Step 1: Enable 2-Step Verification\n1. Go to: https://myaccount.google.com/security\n2. Scroll down to \"How you sign in to Google\"\n3. Click on \"2-Step Verification\"\n4. Follow the setup process\n5. Verify phone number\n6. Done! ✅\n\n### Step 2: Create App Password\n1. Go to: https://myaccount.google.com/apppasswords\n   - **If you don't see this page**, it means 2-Step Verification isn't enabled yet\n2. Select:\n   - \"Mail\"\n   - \"Windows Computer\" (or your device type)\n3. Click \"Generate\"\n4. You'll get a 16-character password like:\n   ```\n   abcd efgh ijkl mnop\n   ```\n5. **Copy the password** (you'll use it in next step)\n\n### Step 3: Add to .env.local\n1. Open your `.env.local` file\n2. Add:\n   ```\n   EMAIL_USER=your.email@gmail.com\n   EMAIL_PASS=abcdefghijklmnop\n   ```\n   **Important:** Remove the spaces from the password\n   - ❌ Wrong: `abcd efgh ijkl mnop`\n   - ✅ Right: `abcdefghijklmnop`\n\n### Step 4: Restart Server\n```bash\nnpm run dev\n```\n\n---\n\n## 🧪 Test Email Sending\n\n### Option 1: Using Browser Console\n```javascript\n// Go to http://localhost:3000/register\n// Open Developer Tools (F12)\n// Go to Console tab\n// Paste this:\n\nfetch('/api/send-verification', {\n  method: 'POST',\n  headers: { 'Content-Type': 'application/json' },\n  body: JSON.stringify({\n    email: 'your.email@gmail.com',\n    name: 'Test User',\n    phone: '+7 123 456 7890'\n  })\n}).then(r => r.json()).then(d => console.log(d))\n```\n\n### Option 2: Using curl (Terminal)\n```bash\ncurl -X POST http://localhost:3000/api/send-verification \\\n  -H \"Content-Type: application/json\" \\\n  -d '{\n    \"email\": \"your.email@gmail.com\",\n    \"name\": \"Test User\",\n    \"phone\": \"+7 123 456 7890\"\n  }'\n```\n\n---\n\n## ✅ Expected Response\n\n### Success (200):\n```json\n{\n  \"success\": true,\n  \"message\": \"Растау коды email-ға жіберілді\",\n  \"code\": \"123456\"\n}\n```\n\n### Error (500):\n```json\n{\n  \"success\": false,\n  \"error\": \"Email service not configured. Please check EMAIL_USER and EMAIL_PASS.\"\n}\n```\n\nIf you get this error:\n1. Check EMAIL_USER is set ✓\n2. Check EMAIL_PASS is set ✓\n3. Check passwords don't have spaces ✓\n4. Restart server ✓\n5. Try again\n\n---\n\n## 🔍 Debugging\n\n### Check Server Logs\nOpen terminal where you ran `npm run dev`\n\nYou should see:\n```\n[Verification] Request started\n[Verification] Email config OK: your.email@gmail.com\n[Verification] Request body parsed: { email: 'user@example.com', hasName: true }\n[Verification] Email validation passed: user@example.com\n[Verification] Code generated: 123456\n[Verification] Storing code in database...\n[Verification] Code stored in database successfully\n[Verification] Starting email send...\n[Verification] Testing SMTP connection...\n[Verification] SMTP connection verified\n[Verification] Sending email to: user@example.com\n[Verification] Email sent successfully: <message-id>\n```\n\n### If You See Errors\n\n**Error: \"Email service not configured\"**\n- Solution: Add EMAIL_USER and EMAIL_PASS to .env.local\n\n**Error: \"SMTP connection failed\"**\n- Check EMAIL_PASS has no spaces\n- Check 2-Step Verification is enabled\n- Try generating new app password\n\n**Error: \"Invalid credentials for\"**\n- Check EMAIL_USER is correct Gmail address\n- Check EMAIL_PASS is app password (not regular password)\n- Check 2-Step Verification is enabled\n\n---\n\n## 📱 Registration Flow\n\n```\n1. Go to /register\n2. Fill in Step 1 (name, email, phone, password)\n3. Fill in Step 2 (city, address)\n4. Click \"Send Code\"\n5. Check your email (inbox or spam)\n6. Copy the 6-digit code\n7. Paste code in Step 3\n8. Click \"Verify and Create Account\"\n9. Account created ✅\n10. Redirected to /profile ✅\n```\n\n---\n\n## 🚨 Common Issues\n\n### \"Email never arrives\"\n- Check Spam/Junk folder\n- Check email address is correct\n- Check console logs for errors\n- Try resending code\n\n### \"Connection timeout\"\n- Internet connection issue\n- Gmail service down (unlikely)\n- Try different WiFi/network\n\n### \"Invalid credentials\"\n- Email password issue\n- 2-Step Verification not enabled\n- App password generated incorrectly\n- Password has spaces (remove them)\n\n---\n\n## ✨ Verification Code Features\n\n✅ **6-digit code** - Random number\n✅ **10-minute expiration** - Code expires after 10 minutes\n✅ **One-time use** - Code deleted after verification\n✅ **Database stored** - Stored in Supabase users table\n✅ **Email sent** - Arrives in seconds\n✅ **Detailed logging** - Full console output for debugging\n\n---\n\n## 📞 Need Help?\n\n1. **Check server logs** - Most info is there\n2. **Verify .env.local** - Make sure all variables set\n3. **Test endpoint** - Use curl or browser console\n4. **Check email config** - Is 2-Step Verification enabled?\n5. **Restart server** - Changes to .env.local require restart\n\n---\n\n**Status:** After following these steps, email verification should work! ✨\n\n
